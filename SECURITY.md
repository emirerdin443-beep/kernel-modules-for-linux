# Security Policy

## Supported Versions

This project is primarily intended for educational purposes.

Security fixes will generally be applied to the latest version of the project.

| Version | Supported |
| ------- | --------- |
| Latest  | Yes       |
| Older versions | No |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it privately rather than opening a public issue.

Please contact the repository maintainer through their GitHub profile:

https://github.com/emirerdin443-beep

When reporting a vulnerability, please include:

- A clear description of the issue
- The affected module or file
- Steps to reproduce the issue
- The expected and actual behavior
- Any relevant logs or technical details

Please do not publicly disclose the vulnerability until it has been reviewed and, where appropriate, addressed.

## Scope

This repository contains Linux kernel modules intended for educational purposes. Kernel modules operate with high privileges, so users should review and test code carefully before loading modules on production systems.

Do not load untrusted kernel modules on systems containing important data.
